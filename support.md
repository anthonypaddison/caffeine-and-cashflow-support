Support is asynchronous. Normal support hours are Monday to Friday, 09:00–17:00 Europe/London. The target initial response is within two business days. This target is not a contractual service-level agreement and does not guarantee a resolution time.

For bugs, feature requests and general support, [open a public GitHub issue](https://github.com/anthonypaddison/caffeine-and-cashflow-support/issues/new). You can also email [support@caffeineandcashflow.co.uk](mailto:support@caffeineandcashflow.co.uk).

## Keep sensitive information private

Do not put any of the following in a public GitHub issue:

- passwords, API tokens or other credentials;
- confidential Confluence content;
- private customer information;
- sensitive personal data; or
- vulnerability details.

For a possible security vulnerability, follow the [private security reporting instructions]({{ '/security/' | relative_url }}) instead.
